# 🎯 Guess the Number Game

A simple React-based number guessing game where the player tries to guess a randomly generated number between **1 and 20**.

This project was created as part of my React learning journey.

---

## 📸 Preview

> Enter a number between **1 and 20** and click **Check** to see if your guess is correct.

### Features

- 🎲 Random number generation
- 🔢 Guess numbers between 1 and 20
- ✅ Instant result display
- ⚛️ Built with React
- ⚡ Powered by Vite

## 🎮 How to Play

1. Enter a number between **1 and 20**.
2. Click the **Check** button.
3. If the guess matches the randomly generated number, you win.
4. Otherwise, try again until you guess the correct number.
